## Evaluation Requirements
For each repository, a trial report must be generated using `reports/v0.5-trials/<trial-id>.md`.

Each evaluation must explicitly follow either:
- **MODE A** (Known Bug Repair) 
- **MODE B** (Open-Ended Responsive Audit)

The outcome for each trial must be strictly categorized according to the **Real-World Failure Classification**:
`STRUCTURAL_BUG`, `INTERACTION_MODEL_BUG`, `VISUAL_UX_ISSUE`, `ACCESSIBILITY_ISSUE`, `INTENTIONAL_BEHAVIOR`, `NO_ISSUE`, `NEEDS_HUMAN_REVIEW`, or `BLOCKED_INCOMPLETE_OBSERVABILITY`.
